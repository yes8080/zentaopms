# 需求池界面对照记录

禅道开源版 22.7，Chromium，简体中文、默认主题，视窗 1440 × 960。原生页面与插件页面使用同一测试实例、账号及普通产品样本。以下截图文件名对应界面对照包。

| 页面 | 原生对照 | 需求池 | 核对结果 |
| --- | --- | --- | --- |
| 列表 | `native-story-list.png` | `feedback-list.png` | 需求池显示编号、标题、产品、客户、负责人、状态、下一步和最近业务更新，可勾选同产品反馈。列配置和原生排序仍待完成。 |
| 新建 | `native-story-create.png` | `feedback-create.png` | 反馈有独立描述和验收标准编辑器，增加客户、渠道和预计负责人。当前提报表单与列表共用页面。原生计划、抄送和评审选项在转单流程中由目标单据处理。 |
| 编辑 | `native-story-edit.png` | `feedback-edit.png` | 反馈从详情展开编辑，保留修订记录。截图核对发现编辑器重复渲染，已修复。浏览器测试验证了两个编辑器各显示一次。 |
| 详情 | `native-story-detail.png` | `feedback-detail.png` | 需求池详情提供正文、验收、业务信息、附件、办理记录和承接单据。需求池已采用桌面双栏布局。左侧显示正文及办理记录，右侧显示基本信息。底部浮动栏可打开编辑和状态操作。窄屏下叠成单栏。 |
| 产品新建、编辑、详情 | `native-product-create.png`、`native-product-edit.png`、`native-product-detail.png` | 禅道原生产品页面内 | 复用原生表单扩展加入需求池负责人选择器，详情负责人区域显示配置状态。 |

## 字段去向

| 字段 | 反馈行为 | 转单行为 |
| --- | --- | --- |
| 产品、平台／分支、模块 | 选择后校验产品归属，附加分支分别保存模块。 | 单张原生需求预填主选分支和模块。 |
| 类别、优先级、来源、关键词、预计工时 | 原生枚举或输入规则，随反馈修订保存。 | 在支持这些字段的原生需求表单预填。 |
| 标题、描述与验收标准 | 标题与两个编辑区独立保存，文本和图片可随修订回显。 | 预填标题与验收文字。客户原话和内嵌图片仍由负责人在原反馈核对。 |
| 客户、渠道、来源备注 | 反馈业务信息，按反馈权限查看。 | 保留在原反馈。 |
| 附件 | 反馈详情上传、下载和移除，下载校验反馈权限。 | 由操作者在目标表单单独确认。 |
| 下一步、剩余事项与对客答复 | 需求池办理历史和状态流转。 | 原生目标的研发进度与反馈独立记录。 |

本轮截图覆盖普通产品。多分支在 Chromium 验证了附加分支和模块的选择、提交与回显，完整截图矩阵以及多平台对照仍待补齐。
