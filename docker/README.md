# 禅道 22.7 Docker 部署

从仓库源码构建 PHP-FPM 和 Nginx，数据库使用 MySQL 8.4。

## 首次运行

仓库根目录自带 `.env`，可以直接启动。默认应用和数据库管理员密码均为 `admin`。用于正式部署时，请在初始化数据库前修改这两个密码。

```sh
docker compose up -d --build
```

打开 `http://127.0.0.1:8080/install.php`。数据库主机填 `mysql`，端口填 `3306`，数据库名、用户名和密码填写 `.env` 中对应的应用账号配置。表前缀使用默认值 `zt_`。完成安装并创建管理员后，打开首页登录并进入产品管理。

默认监听宿主机所有网络接口的 8080 端口。只在本机访问时，可以在 `.env` 中设置 `ZENTAO_BIND=127.0.0.1`。

## 数据与重建

三个命名卷分别保存数据库、安装生成的 `config/my.php` 和上传文件。更新代码后再次执行 `docker compose up -d --build` 可以保留这些卷。备份时同时保存数据库和上传文件。原官方一体化镜像的 `/data` 目录结构不同，迁移现有站点时应导出数据库并迁移上传文件。

`.env` 中的 MySQL 初始化变量只在数据库卷为空时生效。已有数据库应按 MySQL 的账号管理流程修改密码，并同步禅道配置。
